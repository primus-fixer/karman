# «Карман» на общем модуле kit

Общее у «Кармана» и «Полки» переезжает в модуль [kit](https://github.com/primus-fixer/kit), по шагам. Каждый шаг
снаружи ничего не меняет: база, PIN-код, пароль облака, ключ API, связанные устройства и резервные копии
остаются прежними. Что именно не должно измениться, закреплено проверками на образцах файлов 0.15.1
(`crates/karman-core/tests/formats.rs`) и строками ключей в `app/src-tauri/src/names.rs`.

«Полка» прошла те же шаги раньше (0.11.1–0.11.3), поэтому «Карман» переходит на уже проверенный код.

## Шаг 1: вход и ключ базы (0.15.2)

«Карман» больше не держит свою копию кода, который у него и у «Полки» совпадал построчно: ключ базы
в хранилище системы (DPAPI на Windows, Android Keystore на телефоне), Windows Hello, PIN-код с паузами после
ошибок и вход с автоблокировкой.

- Зависимости `kit-core`, `kit-secure`, `kit-tauri` — на коммит kit 0.4.0 (`app/src-tauri/Cargo.toml`); когда
  у kit появится метка `v0.4.0`, ссылка заменяется на метку.
- `app/src-tauri/src/names.rs` — название в трёх падежах и строки ключей. **Строки ключей менять нельзя.**
  Проверка `key_names_are_the_same_as_before_kit` падает, если их тронуть.
- Вход — `kit_tauri::guard`: «Карман» создаёт `Lock` при запуске, отдаёт ему местные настройки базы
  (`StoreMeta`) и говорит, что делать при блокировке (отменить показанный код связи) и при возврате в окно
  (обменяться с облаком).
- Удалены `crates/karman-secure`, `karman-core::pin` и `app/src-tauri/src/guard.rs`.
- Ключ, защищённый DPAPI так, как это делал «Карман» 0.15.1, модуль открывает, и наоборот — это проверяется
  в самом kit на Windows. Хеш PIN-кода из базы 0.15.1 подходит к своему PIN-коду — проверка на образце базы.
- Попутно: команды входа, вызванные в первые мгновения запуска, отвечают «приложение ещё открывается»
  вместо падения.
- «Проверки» на GitHub теперь запускают и тесты моста (`karman-app`), где лежат строки ключей.

### Что проверить

Обновлять поверх 0.15.1, ничего не удаляя.

| Где | Что сделать | Что должно получиться |
|---|---|---|
| Компьютер | Обновить, открыть «Карман» | Всё на месте: операции, поездки, счета, настройки |
| Компьютер | С PIN-кодом: открыть, ввести PIN | Вход как раньше; неверный PIN — «Неверный PIN-код», после пяти ошибок — пауза |
| Компьютер | Настройки → Вход → Windows Hello, заблокировать, войти через Hello | Запрос «Вход в „Карман“» поверх окна, вход проходит |
| Компьютер | «Забыли PIN?» | Подтверждение Windows Hello, затем можно задать новый PIN |
| Компьютер | Свернуть больше чем на 5 минут и вернуться | Экран входа |
| Телефон | Обновить, открыть | Всё на месте |
| Телефон | Вход по отпечатку; «Забыли PIN?» | Отпечаток работает; сброс — через блокировку экрана телефона |
| Компьютер и телефон | Настройки → Облако → «Обменяться сейчас» | Обмен без повторного ввода пароля |
| Компьютер и телефон | Обмен по Wi-Fi → «Обменяться» у связанного устройства | Обмен проходит, связывать заново не нужно |
| Компьютер | Показать код связи и заблокировать «Карман» | Код отменён: после входа его нужно показать заново |
| Компьютер или телефон | «Спросить Claude» | Отвечает без повторного ввода ключа API |
| Компьютер | Заблокировать «Карман» и спросить Claude в приложении Claude | Коннектор отвечает, что «Карман» заблокирован; после входа — работает |
