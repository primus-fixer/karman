# Личное облако: Яндекс Диск (версия 0.13.0)

Компьютер и телефон обмениваются записями и снимками чеков через ваш Яндекс Диск — в командировке общий
Wi-Fi не нужен. На Диске лежат только зашифрованные файлы в папке «Карман»: прочитать их можно только
паролем копий, ни Яндекс, ни кто-то с доступом к Диску их не откроет.

Вход — по логину Яндекса и **паролю приложения** (WebDAV). Вместо Яндекс Диска можно подключить свой
сервер WebDAV: Nextcloud, Synology или другой NAS. Обмен по Wi-Fi напрямую остаётся и работает вместе с облаком.

## Пароль приложения Яндекса

«Карман» не принимает основной пароль от аккаунта Яндекса — только пароль приложения. Он открывает только Диск,
его можно удалить в любой момент, а основной пароль остаётся в тайне.

1. Откройте [Яндекс ID → Безопасность](https://id.yandex.ru/security) (в «Кармане» — кнопка «Открыть Яндекс ID»).
2. «Доступ к вашим данным» → «Пароли приложений» → тип **«Файлы WebDAV»** (WebDAV-клиент для Диска).
3. Назовите его, например, «Карман» → «Далее». Яндекс покажет пароль **один раз** — сразу скопируйте.
4. Новый пароль начинает действовать **через 2–3 часа**. Если «Карман» сразу пишет «Яндекс не принял логин
   или пароль приложения» — подождите и попробуйте снова.

Вход по WebDAV Яндекс открывает в тарифах Яндекс 360.

## Подключить

**Компьютер.** Настройки → Синхронизация → «Личное облако» → «Яндекс Диск» → логин Яндекса и пароль
приложения → «Войти». Затем пароль копий:

- если на компьютере уже есть пароль резервных копий — введите его, облако шифруется им же;
- если нет — придумайте (не короче 8 символов, лучше фраза из нескольких слов) и запишите: он же станет
  паролем резервных копий.

**Телефон и другие устройства.** «Личное облако» → «Яндекс Диск» → свой пароль приложения (можно тот же
или отдельный для телефона) → **тот же пароль копий**. Без пароля копий новое устройство данные из облака
не получит.

**Свой сервер.** «Другой сервер WebDAV» → адрес папки WebDAV (например,
`https://cloud.example.ru/remote.php/dav/files/имя` для Nextcloud), логин и пароль. Нужен https с настоящим
сертификатом: без шифрования пароль ушёл бы по сети открытым.

## Как идёт обмен

Сам: вскоре после запуска «Кармана», через минуту после изменений, каждые 15 минут, пока «Карман» открыт,
и при возвращении в него. «Только по кнопке» оставляет одну кнопку «Обменяться сейчас». На экране —
когда был последний обмен, сколько записей получено и отправлено, сколько снимков чеков ещё придёт.

Пока «Карман» заблокирован PIN-кодом, обмен продолжается в фоне, а экран данных не показывает.

## Что лежит на Диске

В папке «Карман» в корне Диска:

- `karman.key` — ключ облака, зашифрованный паролем копий (Argon2id);
- `e/…kev` — записи устройств пачками, сжатые и зашифрованные (XChaCha20-Poly1305);
- `b/…kbl` — снимки и PDF чеков, зашифрованные; по имени файла нельзя узнать, какой это снимок.

Названий операций, сумм, городов и снимков в открытом виде на Диске нет. Подменённый или переименованный
файл не расшифруется — «Карман» его не примет.

## Безопасность

- Пароль приложения хранится только на этом устройстве: в зашифрованной базе и под защитой системы
  (DPAPI на Windows, Android Keystore на телефоне). В обмен, облако и резервные копии он не попадает.
- Пароль копий нигде не хранится в открытом виде; на компьютере — как у резервных копий.
- «Карман» работает только в своей папке «Карман» и не читает другие файлы на Диске.
- Смена пароля копий на компьютере (Настройки → Резервная копия) перешифровывает ключ облака: новый пароль
  уйдёт в облако при ближайшем обмене. Подключённые устройства продолжают обмен, новое устройство
  подключается уже новым паролем.

## Если что-то пошло не так

- **«Яндекс не принял логин или пароль приложения»** — пароль приложения удалили, он ещё не начал действовать
  (2–3 часа) или это пароль от аккаунта. Создайте новый пароль приложения и введите его: «Войти снова» —
  обмен продолжится, пароль копий не нужен.
- **«Яндекс Диск не пускает по WebDAV (ответ 403)»** — проверьте подписку Яндекс 360 и тип пароля приложения.
- **«В облаке не хватает места»** — освободите место на Диске; обмен повторится сам.
- **«Нет связи с облаком»** — обмен повторится через несколько минут.
- **«Облако подключили заново на другом устройстве»** — введите пароль копий ещё раз.

## Отключить

«Отключить» — облако перестаёт использоваться на этом устройстве, данные в облаке остаются, его можно
подключить снова. Галочка «Удалить данные «Кармана» из облака» — удалить файлы «Кармана» с Диска (свои
файлы в папке «Карман», если вы их туда положили, остаются); другие устройства тоже перестанут обмениваться
через облако, на самих устройствах всё останется. Пароль приложения после этого можно удалить в Яндекс ID.

## Что проверить на устройствах

| Где | Что сделать | Что должно получиться |
| --- | --- | --- |
| Яндекс ID | Создать пароль приложения «Файлы WebDAV», подождать 2–3 часа | Пароль из 16 букв сохранён |
| Компьютер | Настройки → Синхронизация → «Личное облако» → «Яндекс Диск» → логин и пароль приложения | «Яндекс Диск: вход выполнен» |
| Компьютер | Ввести пароль копий | «Яндекс Диск подключён», через несколько секунд — «Последний обмен: … отправлено N» |
| Яндекс Диск | Открыть папку «Карман» | `karman.key`, папки `e` и `b`; файлы не читаются |
| Телефон | «Личное облако» → «Яндекс Диск» → пароль приложения → пароль копий | Записи и снимки чеков пришли с компьютера |

| Компьютер | «Отключить» с галочкой «Удалить данные» | Папка «Карман» на Диске пуста или удалена |
