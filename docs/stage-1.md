# Этап 1: экраны на настоящих данных и защита входа

Вместо экрана «Проверки» — приложение из макета: обзор, лента, поездки с отчётом для 1С, быстрый ввод и настройки.
Всё считает ядро на Rust по правилам из [rules.md](rules.md), данные хранятся в зашифрованной базе.

## Что появилось

- **Обзор:** «Мои деньги» (на счетах минус подотчётные и то, что нужно вернуть компании), открытые поездки, операции за сегодня.
- **Лента:** операции по дням, отдельно личное и поездки. Нажмите на операцию — подробности, «Документ есть», «Удалить» (удаление можно отменить в сообщении внизу).
- **Поездки:** создание по заявке из 1С (номер, даты, суммы по статьям 03.01.04.01–05), статусы от заявки до закрытия.
  - «Отметить выдачу аванса» записывает аванс на рабочий счёт — сумма равна заявке.
  - **Итоги:** расчёт с компанией и суточные; своя ставка суточных для поездки.
  - **Для 1С:** «Заявка» и «Авансовый отчёт» — нажмите на поле или сумму, и они скопируются для вставки в 1С. Сверх бюджета — с обоснованием, его можно поправить.
  - **Документы:** какие чеки отправлены в офис; расходы без документа — из суточных, сверх них долг перед компанией.
  - «Деньги возвращены» / «Возмещение получено» закрывают расчёт операцией возврата или возмещения.
- **Быстрый ввод** (кнопка «+» на телефоне, «Новая операция» на компьютере): расход или доход, текущая поездка, личное или «личное, метка поездки», категория, счёт, дата, комментарий. Для расходов поездки — отметка чека: фото, QR-код (на телефоне сканирует кассовый чек и заполняет сумму и дату), файл.
- **Настройки:** ставка суточных, счета и их остатки (тип: рабочий, личный, наличные; валюта), курсы валют, связь по Wi-Fi, тема и цветовая схема, сведения об устройстве и проверки.

## Защита входа (версия 0.3.0)

- **Ключ базы — в хранилище системы.** На Windows он зашифрован вашей учётной записью Windows (DPAPI),
  на Android — ключом из защищённого хранилища телефона (Android Keystore). Открытый файл ключа прежних версий
  переносится туда при первом запуске и стирается — только после того, как защищённая копия записана и проверена.
  Скопированная база без вашего устройства не открывается.
- **PIN-код из 4 цифр** — у каждого устройства свой, между устройствами не передаётся. Спрашивается при запуске
  и после 5 минут в фоне. После 5 ошибок — пауза 30 секунд, дальше она растёт (минута, 5 минут, 15 минут, час)
  и сохраняется даже после перезапуска.
- **Отпечаток пальца** на Android и **Windows Hello** на компьютере (отпечаток, лицо или PIN Windows — что настроено).
  Экран входа сам предлагает отпечаток, PIN-код остаётся запасным.
- **Забыли PIN?** — подтвердите себя блокировкой экрана телефона или Windows Hello и задайте новый PIN. Данные остаются.
- Пока «Карман» заблокирован, ядро не отдаёт данные никому — даже собственному интерфейсу.

Включается в **Настройки → Защита**: «Задать PIN», затем переключатель отпечатка или Windows Hello.

## Снимки чеков (версия 0.4.0)

- **В быстром вводе** кнопка «Фото» на телефоне открывает камеру, на компьютере — выбор снимка. «Файл» — снимки и PDF
  (билеты, счета гостиниц). Можно прикрепить несколько. Бумажный чек без снимка — «Чек есть, сниму позже».
- **К записанной операции** — «Снимок чека» в подробностях операции или «Добавить снимок» в разделе «Документы» поездки.
- Снимки уменьшаются до 1600 точек (чек читается, файл весит 200–400 КБ) и хранятся **в зашифрованной базе**.
  Принимаются только JPEG, PNG, WebP и PDF до 15 МБ — по содержимому файла, а не по названию.
- **Синхронизация по Wi-Fi передаёт снимки** вместе с операциями: снятый на телефоне чек появляется на компьютере.
  Каждый снимок проверяется по отпечатку SHA-256 — подменённый или повреждённый файл не примется.
- **Архив чеков для офиса** (на компьютере): «Документы» поездки → «Архив чеков в „Загрузки“». Внутри файлы с именами
  «дата название сумма», например `2026-11-05 Такси до объекта 640,00.jpg`.
- Синхронизация стала совместимой с будущими версиями: если на одном устройстве версия новее, записи нового вида
  не теряются на другом, а оживают после его обновления.

Пока не сделано: облако, долги и семейные траты (этап 2).

## Установка

1. В PR этапа 1 откройте **Checks** → **Сборки**, или **Actions** → последний запуск **«Сборки»** с зелёной отметкой.
2. **Windows:** скачайте `karman-windows`, запустите установщик — он обновит прежнюю версию. Проверочные операции этапа 0 удалятся сами.
3. **Android:** скачайте `karman-android`.
   - Версию этапа 0 сначала **удалите** с телефона: она подписана временным ключом, и новая поверх неё не встанет.
   - Файл называется `Karman-<версия>.apk`, если подключён постоянный ключ (см. ниже), или `Karman-<версия>-debug.apk` без него.
   - С постоянным ключом следующие версии будут ставиться поверх, без удаления и без потери данных.

### Постоянный ключ подписи для Android

Один раз добавьте в репозиторий два секрета: **Settings → Secrets and variables → Actions → New repository secret**.

| Имя | Значение |
|---|---|
| `ANDROID_KEYSTORE` | содержимое файла с ключом в base64 (одна длинная строка) |
| `ANDROID_KEYSTORE_PASSWORD` | пароль ключа |

После этого перезапустите «Сборки» (**Actions → Сборки → Run workflow**, ветка `stage-1`). Файл с ключом храните
в надёжном месте: без него обновления для уже установленного приложения собрать не получится.

## Что проверить

| Что | Как | Что должно получиться |
|---|---|---|
| Остатки | Настройки → Счета → укажите, сколько сейчас на картах и наличными | «На счетах» в обзоре совпадает с суммой |
| Поездка | Поездки → «Новая поездка», перенесите заявку из 1С | Итог по заявке совпадает с 1С |
| Аванс | В поездке «Отметить выдачу аванса» | На рабочем счёте прибавилась сумма заявки |
| Расход с чеком | «+» → сумма → «Фото» или «QR-код» → записать | В отчёте для 1С сумма в своей статье |
| Расход без чека | «+» → сумма без отметки чека | Вычитается из суточных; если их не хватает — долг перед компанией |
| Личное | «+» → «Личное» | В ленте с фильтром «Личное», поездку не меняет |
| Отчёт для 1С | Поездка → «Для 1С» → нажать на сумму | Сумма вставляется в 1С как `66358,90` |
| Связь | Настройки → Синхронизация: компьютер «Показать QR-код», телефон «Сканировать QR-код» | Поездки и операции появились на втором устройстве |
| PIN-код | Настройки → Защита → «Задать PIN», затем закрыть и открыть «Карман» | Экран входа, после верного PIN — ваши данные |
| Отпечаток | Включить «Вход по отпечатку» (на Windows — «Вход через Windows Hello»), нажать «Заблокировать сейчас» | Система сама спрашивает отпечаток или Windows Hello |
| Ошибки | Пять раз ввести неверный PIN | Пауза 30 секунд, клавиши недоступны |
| Забыли PIN | «Забыли PIN?» на экране входа | Блокировка экрана телефона или Windows Hello, затем новый PIN |
| Фон | Свернуть «Карман» больше чем на 5 минут | При возврате — экран входа |
| Снимок чека | «+» → расход в поездку → «Фото» → снять чек → записать | В подробностях операции миниатюра, по нажатию — снимок целиком |
| Снимок на компьютере | Связать устройства по Wi-Fi после снимка на телефоне | Тот же снимок в операции на компьютере |
| Архив для офиса | Компьютер: поездка → «Документы» → «Архив чеков в „Загрузки“» | В «Загрузках» архив с чеками поездки |

Если что-то считается не так, как в 1С, — пришлите номер поездки и что ожидали.
