# Обмен по Wi-Fi: поиск в сети и связь по коду (версия 0.15.0)

Компьютер и телефон в одной сети Wi-Fi находят друг друга сами. Связать их нужно один раз — по коду из восьми
знаков, как в «Мосте». Дальше связанные устройства обмениваются сами, пока «Карман» открыт. Облако для этого
не нужно; обмен по Wi-Fi и через Яндекс Диск работают вместе.

## Связать устройства

1. **На одном устройстве** — Настройки → Синхронизация → «Показать код». Появится код вроде `6WVG-HEWK`,
   QR-код и адрес устройства в сети. Код действует пять минут и срабатывает один раз.
2. **На другом устройстве** — Настройки → Синхронизация. В списке «Рядом в сети» появится первое устройство
   с пометкой «показан код». Нажмите «Ввести код» и введите код — можно маленькими буквами, без дефиса и даже
   русскими «В», «Е», «К», «М», «Н», «Р», «С», «Т», «Х», если удобнее с русской раскладки.
   **На телефоне** проще «Сканировать QR-код» — код и адрес в нём.
3. Сразу пройдёт первый обмен: «Связано с «Ноутбук»: отправлено N, получено M». Оба устройства появятся друг
   у друга в «Связанных устройствах».

Если устройства нет в списке «Рядом в сети» (так бывает, если роутер не пропускает поиск между устройствами
или его не разрешил брандмауэр Windows), нажмите «Нет в списке? Связать по адресу» и введите адрес, который
показан под кодом на первом устройстве, и сам код.

Код можно ввести неверно четыре раза — «Код не подошёл. Осталось попыток: …». После пятой неверной попытки код
отменяется: покажите новый.

## Связанные устройства

- В списке — имя, «В сети» или «Не в сети» и когда был последний обмен.
- **Обмен сам**: связанные устройства в одной сети находят друг друга и обмениваются вскоре после изменений
  и раз в минуту, пока «Карман» открыт (на компьютере — и в трее, и пока «Карман» заблокирован PIN-кодом,
  как с облаком).
- **«Обменяться»** — обменяться сейчас.
- **«Отвязать»** — обмен по Wi-Fi с этим устройством прекращается, записи остаются на обоих. На другом
  устройстве при следующей попытке обмена будет «… не узнало это устройство». Связать снова можно по новому коду.

Связать можно несколько устройств: компьютер с телефоном, второй компьютер, планшет.

## Безопасность

- Код по сети не передаётся. Из кода оба устройства получают общий ключ по SPAKE2: подслушав обмен, код не
  узнать и не подобрать у себя — проверить вариант кода можно только попыткой на самом устройстве, а попыток пять.
- Устройство, которое не знает кода (например, подставное с тем же именем в списке), ничего не получит:
  ключ подтверждают обе стороны, и только потом идёт обмен — «Ответило не то устройство».
- После связи у пары свой ключ. Он хранится только на этих двух устройствах: в зашифрованной базе и под защитой
  системы (DPAPI на Windows, Android Keystore на телефоне). В облако, резервные копии и обмен с другими он не попадает.
- У каждого обмена — свои ключи из ключа пары и случайных чисел обеих сторон, у каждого пакета — свой номер:
  записанный когда-то обмен не повторить, пакеты не переставить и не подменить.
- Чужим в сети — в гостинице, в кафе — «Карман» на поиск не отвечает: отвечает, только пока показан код,
  и связанным устройствам (их запрос подписан ключом пары). Порт обмена открыт, только пока есть связанные
  устройства или показан код.
- Пока «Карман» заблокирован, кода нет: показать его можно только после входа, блокировка код отменяет.
- Адрес, введённый руками, — только адрес домашней сети (192.168…, 10…, 172.16–31…).

Подробнее — [docs/security-3.md](security-3.md).

## Брандмауэр Windows

Когда на компьютере впервые показан код, Windows может спросить, разрешить ли «Карману» доступ к сети.
Разрешите для частных сетей — иначе телефон не найдёт компьютер и не подключится. Если окно закрыли, разрешение
можно дать в «Безопасность Windows» → «Брандмауэр и защита сети» → «Разрешить работу с приложением через брандмауэр».

## Совместимость

- «Карман» 0.14 и старше показывает QR-код с ключом. Телефон с 0.15 такой QR-код читает: обмен пройдёт один раз,
  а устройства друг друга не запомнят — обновите и второе устройство.
- QR-код из 0.15 «Карман» 0.14 не прочитает: «QR-код от более новой версии приложения». Обновите устройство.
- Вставки ссылки «karman://pair…» больше нет: код короче и надёжнее.

## Что проверить на устройствах

| Где | Что сделать | Что должно получиться |
| --- | --- | --- |
| Компьютер | Обновить «Карман» до 0.15.0 | Данные на месте; в Синхронизации — «Показать код» и «Рядом в сети», вставки ссылки нет |
| Компьютер | «Показать код» | Код из восьми знаков, QR-код, адрес; Windows может спросить про брандмауэр — разрешить |
| Телефон | Обновить до 0.15.0, Настройки → Синхронизация | В «Рядом в сети» — компьютер с пометкой «показан код» |
| Телефон | «Ввести код» → код с компьютера | «Связано с …», на обоих — в «Связанных устройствах» |
| Телефон | Ввести неверный код | «Код не подошёл. Осталось попыток: 4» |
| Телефон | Записать расход, подождать полминуты | Расход появился на компьютере сам |
| Компьютер | Записать расход при открытом «Кармане» на телефоне | Расход появился на телефоне сам |
| Телефон | Выключить Wi-Fi | Компьютер: телефон «Не в сети» |
| Телефон | «Сканировать QR-код» с другого устройства с кодом | Связано без ввода кода |
| Компьютер | «Отвязать» телефон | Телефон больше не обменивается: «… не узнало это устройство» |
| Компьютер | «Показать код», затем «Заблокировать сейчас» и войти | Кода больше нет |
