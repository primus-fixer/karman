# ИИ в «Кармане»: распознавание нарядов (версия 0.12.0)

Claude читает снимки или PDF наряда-допуска и заполняет за вас наряд и время работы по дням.
Перед записью «Карман» показывает всё, что прочитал Claude, и сохраняет только то, что вы проверили.

## Что нужно

Ключ API Claude — свой. Запросы к Claude оплачиваются с вашего счёта в Claude Console, отдельно
от подписки на Claude.

1. Войдите в [Claude Console](https://platform.claude.com) и пополните баланс (раздел Billing).
2. Откройте [API keys](https://platform.claude.com/settings/keys) → **Create key**. В поле Workspace выберите
   одно пространство, например Default — тогда кроме ключа ничего вводить не придётся.
3. Скопируйте ключ (Console показывает его один раз) и вставьте в «Кармане»: **Настройки → ИИ** →
   «Подключить». «Карман» сразу проверит его одним коротким запросом.

Если ключ создан для всех пространств, Claude API попросит ID пространства: «Ключ не привязан
к пространству» в том же разделе, ID (`wrkspc_…`) — в Claude Console на странице Workspaces.

На телефоне и на компьютере ключ вводится отдельно: он не переходит при обмене по Wi-Fi.

## Как распознать наряд

1. В поездке → «Наряды» → «Добавить наряд» → снимки всех листов («Снять» на телефоне) или PDF.
   Можно и у наряда, который уже записан.
2. «Распознать». Claude читает листы — обычно до минуты.
3. Проверьте экран «Claude прочитал наряд»: номер, даты, объект и работы, с какого дня вы в бригаде
   и дни. Время любого дня можно поправить, лишний день — снять галочкой.
4. «Сохранить наряд и N дней». После записи — «Вернуть», если что-то не так.

Ничего не записывается, пока вы не нажмёте «Сохранить». «Отмена» — как будто и не распознавали.

## Или в приложении Claude

На компьютере наряд можно разобрать и в приложении Claude — через коннектор ([docs/claude.md](claude.md)),
по вашей подписке, без ключа API: приложите снимок или PDF наряда в чат и попросите записать наряд
и дни в поездку. Claude прочитает наряд сам, а время дней посчитает «Карман» — по тем же правилам,
что ниже. Claude покажет дни и запишет их после вашего согласия одной записью с кнопкой «Вернуть».
Нужно включить «Разрешить запись» в Настройки → Claude. Снимки из разговора в «Карман» не попадают —
добавьте их в «Наряды» → «Снимок», чтобы наряд вошёл в папку отчёта.

## Как получается время дня

Как в таблице переработок:

- **будни** — с начала рабочего дня (8:00), окончание — по наряду, но не раньше конца рабочего дня (17:00);
- **выходные и праздники** — по наряду, как есть (по производственному календарю);
- **допуск вечером** — если в будни бригаду допустили после 17:00, время тоже по наряду;
- работа после полуночи остаётся днём начала: 8:00 – 1:10;
- **дни до ввода в бригаду не берутся**: Claude находит вас в таблице «Изменения в составе бригады»
  по ФИО из Настройки → Переработки. Если вы выведены из бригады — не берутся дни после вывода.

Начало и конец рабочего дня — в Настройки → Переработки. Комментарий дня — «Объект и работы» из наряда,
если в дне уже не вписан свой.

Дни, где время уже вписано вами, без спроса не заменяются: они показаны без галочки, рядом — что
записано сейчас. Поставьте галочку, если нужно заменить.

Если ФИО в настройках не указано или в наряде не нашлось, «Карман» скажет об этом — тогда дни
не отсеиваются по составу бригады, решаете вы.

## Сколько стоит

Наряд читает Claude Opus 5.5 (4 $ за миллион токенов на входе и 20 $ на выходе). Лист наряда —
около 4,7 тыс. токенов, ответ с рассуждением — 2–4 тыс., поэтому наряд из четырёх листов стоит
примерно 0,1–0,15 $. Проверка ключа делается моделью Claude Haiku 5.5 — доли цента.

В Настройки → ИИ — сколько запросов в этом месяце и всего, с оценкой в долларах (и в рублях
по курсу из «Кармана»). Точная сумма — в Claude Console.

## Безопасность

- Ключ хранится только на этом устройстве: он зашифрован средствами системы (DPAPI на Windows,
  Android Keystore на телефоне) и лежит в зашифрованной базе. В обмен по Wi-Fi и в резервные копии
  ключ не попадает. На экране — только его хвост: `sk-ant-…a1B2`.
- В Anthropic уходят листы наряда и даты поездки — только когда вы нажимаете «Распознать».
  Остальные данные «Кармана» остаются на устройстве.
- Пока «Карман» заблокирован PIN-кодом, ИИ не работает.
- Распознавание выключается в Настройки → ИИ; «Удалить» стирает ключ с устройства.

## Если не получилось

«Карман» пересказывает ответ Claude API по-русски:

- «Ключ API не подходит» — ключ отозван, истёк или скопирован не целиком;
- «На счёте Claude Console не хватает средств» — пополните баланс;
- «Ключ не привязан к рабочему пространству» — впишите ID пространства или создайте ключ для одного пространства;
- «Claude API сейчас перегружен», «Слишком много запросов» — повторите позже;
- «Claude ответил не по форме» — повторите; запрос учтён в счётчике, как и в Claude Console.

Claude API доступен не во всех странах — список поддерживаемых стран у Anthropic.
