# Этап 0: проверка на устройствах

Цель — убедиться, что основа работает на вашем компьютере и телефоне, прежде чем строить экраны.

## Установка

1. Откройте репозиторий на GitHub → **Actions** → последний запуск **«Сборки»** с зелёной отметкой.
2. Внизу, в **Artifacts**, скачайте `karman-windows` и `karman-android`.
3. **Windows:** распакуйте архив и запустите установщик `.exe`. Windows может предупредить, что издатель
   неизвестен: «Подробнее» → «Выполнить в любом случае». Это нормально — сборка пока без подписи.
4. **Android:** перешлите `.apk` на телефон и откройте его. Телефон попросит разрешить установку из этого
   источника — разрешите. Если Play Защита спросит про неизвестное приложение — «Всё равно установить».

## Что проверить

На каждом устройстве откройте «Карман» — там один экран «Проверки».

| Проверка | Как | Что должно получиться |
|---|---|---|
| База | «Проверить базу» | Все пять пунктов с зелёными галочками |
| Расчёт | «Посчитать» | 573: вернуть 66 358,90 и израсходовано 55 641,10, как в 1С |
| Связь | На компьютере «Показать QR-код», на телефоне «Сканировать QR-код» | «Обмен с …: отправлено N, получено M» |
| Обмен | Добавить операцию на одном устройстве, снова связаться | Операция появилась на втором устройстве |
| Точка доступа | Раздать интернет с телефона, подключить компьютер, повторить связь | Обмен проходит без домашнего Wi-Fi |
| Чек | На телефоне «Сканировать чек» на любом кассовом чеке | Дата, сумма, ФН, ФД, ФП |

Если что-то не получилось — пришлите снимок экрана и напишите, на каком устройстве и в какой сети.
