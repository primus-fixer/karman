# Коннектор для Claude (версия 0.11.0)

«Карман» на компьютере подключается к приложению Claude как расширение. В разговоре с Claude можно
спрашивать о деньгах и поездках, а если разрешить запись — просить записать расход, рабочий день или наряд.

Примеры:

- «Сколько у меня денег и что нужно вернуть компании?»
- «Что я потратил на такси в октябре?»
- «Сколько суточных осталось в поездке 588 и каких чеков не хватает для отчёта?»
- «Запиши такси 640 рублей в текущую поездку, чек есть».
- «Поставь на 30 октября в поездке 573 работу с 8:00 до 21:30, испытания».
- «Собери отчёт по переработкам за октябрь».
- «Вот наряд — запиши его и дни в поездку 573» (снимок или PDF наряда — в чат).

Те же вопросы можно задать и в самом «Кармане» — «Спросить Claude» (с 0.13.0, по ключу API, на компьютере
и на телефоне, [docs/ai.md](ai.md)). Инструменты у них общие, а разрешение на запись — своё: «Разрешить запись»
здесь для приложения Claude, «Claude может записывать» в Настройки → ИИ — для «Спросить Claude».

## Как подключить

1. В «Кармане»: **Настройки → Claude** → включите «Подключение для Claude». Запись — отдельным
   переключателем «Разрешить запись».
2. Там же — «Скачать расширение»: в «Загрузках» появится файл «Карман для Claude.mcpb».
3. Откройте его двойным щелчком — приложение Claude предложит установить расширение. Или в приложении
   Claude: Настройки → Extensions → Advanced settings → Install Extension… и выберите файл.
4. Спросите Claude о деньгах. Если «Карман» закрыт, он откроется сам.

Если расширение не ставится, в «Кармане» есть «Ручная настройка»: готовый текст для файла настроек
приложения Claude (`claude_desktop_config.json`) — скопируйте его и перезапустите приложение Claude.

## Что Claude может

**Читать** (когда подключение включено): сводку («Мои деньги», подотчётные, вернуть компании, долги,
отложенное, ближайшие платежи), счета, операции за период с поиском, поездки и расчёт по каждой
(авансовый отчёт для 1С по статьям, документы), переработки по поездке и за месяц, бюджет, статистику,
долги и регулярные платежи.

**Записывать** (только если «Разрешить запись» включено):

- расход или доход — по тем же правилам, что окно ввода: в поездке рабочий расход (с документом идёт
  в отчёт 1С, без документа — из суточных), питание, аванс или возмещение; вне поездки — личный или
  семейный расход, доход; счёт по умолчанию — рабочая карта для поездки и личная для остального;
- исправить или удалить операцию;
- рабочий день и наряд (без снимков — их добавляете в «Кармане»);
- наряд со снимка или PDF вместе с днями (с 0.12.0): Claude читает наряд сам, по вашей подписке,
  а время дней считает «Карман» — по тем же правилам, что «Распознать» в самом «Кармане»
  ([docs/ai.md](ai.md)): будни с 8:00 и не раньше 17:00, выходные и вечерний допуск — по наряду,
  дни до вашего ввода в бригаду не берутся, уже вписанное вами время без спроса не заменяется.
  Claude показывает дни и записывает наряд с днями после вашего согласия — одной записью
  с одной кнопкой «Вернуть»;
- новую поездку по заявке;
- отчёт по переработкам в «Загрузки».

Каждое действие Claude «Карман» показывает сообщением с кнопкой «Вернуть», а в Настройках → Claude —
списком «Последние действия Claude» с кнопкой «Отменить». Отменить нельзя, если после Claude запись
уже правили, — тогда «Карман» так и скажет. Список действий — с последнего запуска «Кармана»;
сами записи остаются в ленте как обычные.

## Безопасность

- «Карман» ничего не открывает в интернет. Приложение Claude запускает `karman.exe --mcp`, а тот
  передаёт запросы запущенному «Карману» только внутри этого компьютера (127.0.0.1) и только с ключом,
  который «Карман» каждый раз заново пишет в свою папку данных.
- Claude видит только то, что запросит в разговоре по вашей просьбе, — это уходит в Anthropic вместе
  с разговором. Остальные данные остаются на компьютере.
- Пока «Карман» заблокирован PIN-кодом, Claude ничего не получает: «Карман» открывает окно входа,
  а Claude просит вас войти. С PIN-кодом «Карман» блокируется через 5 минут в фоне.
- Запись выключена, пока вы её не разрешите; подключение целиком выключается одним переключателем.
- Ключ API для коннектора не нужен: разговор идёт в вашем приложении Claude, по вашей подписке.

## Ограничения

- Коннектор — в «Кармане» на компьютере (Windows) и в приложении Claude на этом же компьютере.
  Для claude.ai в браузере и на телефоне нужен удалённый коннектор со своим сервером — это этап 3.
  Записи, сделанные Claude на компьютере, приходят на телефон при обмене по Wi-Fi.
- Для счетов в валюте Claude берёт сохранённый курс ЦБ (или курс из настроек), не запрашивая сайт ЦБ.
