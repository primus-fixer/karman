# Карман

Приложение для компьютера (Windows) и телефона (Android): личные деньги и командировки в одном месте.
Суточные, авансовые отчёты для 1С, долги и синхронизация между устройствами без чужих серверов.

Макет интерфейса — в артефакте «Карман» в Claude. Правила расчёта командировок — в [docs/rules.md](docs/rules.md).

## Что сейчас готово

**Этап 1** — приложение на настоящих данных:

- обзор: «Мои деньги», подотчётные, что вернуть компании и что она должна;
- лента операций по дням — всё, личное, поездки;
- поездки по заявке из 1С: аванс, суточные, расходы с документами и без, расчёт с компанией;
- отчёт для 1С — заявка и авансовый отчёт с копированием полей, сверх бюджета с обоснованием;
- быстрый ввод с метками «поездка», «личное», «личное, метка поездки», QR-код кассового чека;
- снимки и файлы чеков в зашифрованной базе, обмен ими по Wi-Fi, архив чеков поездки для офиса;
- счета и остатки, валюты, ставка суточных, темы оформления;
- вход по PIN-коду, отпечатку пальца (Android) или Windows Hello; ключ базы — в хранилище системы;
- зашифрованная база и связь устройств по Wi-Fi из этапа 0.

Как установить и что проверить — [docs/stage-1.md](docs/stage-1.md). Проверки этапа 0 — [docs/stage-0.md](docs/stage-0.md).

**Этап 2** — личные финансы, идёт частями ([docs/stage-2.md](docs/stage-2.md)):

- переводы между своими счетами: снятие наличных, обмен валюты — «Мои деньги» не меняются;
- курсы ЦБ на дату операции (с сайта ЦБ запрашивается только дата), запасные курсы в настройках;
- метка «Семья» для общих расходов;
- синхронизация разных версий: устройства знают версии друг друга и подсказывают, какое обновить;
- долги «я должен» и «мне должны», кредиты с графиком платежей;
- регулярные платежи: «Оплачено» и «Пропустить», автоплатежи записываются сами;
- напоминания: уведомления Android и Windows (без сумм), за сколько дней — в настройках;
- «Отложено»: накопительные счета и вклады отдельно от «Моих денег», прогноз процентов по вкладам;
- цели с переводами на копилку и суммой «сколько откладывать в месяц»;
- бюджет на месяц: личный и семейный, общий лимит и по категориям, подсказка при вводе;
- статистика за месяц, квартал и год: расходы по категориям, доходы и расходы по месяцам, командировки за год;
  выгрузка в Excel на компьютере.

**Резервные копии** (0.9.0, [docs/backup.md](docs/backup.md)): все записи и снимки чеков в одном файле,
зашифрованном паролем копии; автокопии на компьютере в выбранную папку (например, Яндекс Диска),
восстановление на компьютере и на телефоне — записи добавляются к нынешним.

## Как устроено

```
crates/karman-core/   ядро на Rust: деньги, даты, поездки, долги и платежи, бюджет, накопления, статистика, выгрузка в Excel, резервные копии, база, синхронизация, QR, PIN-код, курсы ЦБ
crates/karman-secure/ ключ базы в хранилище системы (DPAPI, Android Keystore) и Windows Hello
app/                  приложение Tauri 2: интерфейс (React) и мост к ядру (src-tauri)
scripts/              донастройка Android-проекта при сборке
.github/workflows/    проверки и сборки
docs/                 правила расчёта и план проверки
```

Одно ядро на Rust работает и на Windows, и на Android. Интерфейс — веб-страница внутри приложения,
поэтому экраны одинаковые на обоих устройствах.

Синхронизация: каждое изменение — событие в журнале с номером от устройства. Устройства обмениваются
недостающими событиями, при споре побеждает более позднее изменение. Wi-Fi, облако и свой сервер
передают одни и те же зашифрованные пакеты.

## Сборки

Каждый пуш запускает «Сборки» в Actions. Готовые файлы — в разделе Artifacts у запуска:

- `karman-windows` — установщик `.exe` и `.msi`;
- `karman-android` — `.apk` для телефона. С секретами `ANDROID_KEYSTORE` и `ANDROID_KEYSTORE_PASSWORD`
  он подписан постоянным ключом и обновляется поверх, без них — отладочная сборка.

## Разработка

Нужны Rust, Node.js 22, для Android — Android Studio с NDK.

```bash
cargo test -p karman-core        # тесты ядра
cargo run -p karman-core --example demo_snapshot > demo.json   # сводка на демо-данных макета
cd app && npm ci
npm run tauri dev                # приложение на компьютере
npm run tauri android dev        # на телефоне по USB
```

## План

1. **Этап 0** — проверки на устройствах (готово).
2. **Этап 1** — первая версия: быстрый ввод, лента, поездки и отчёт для 1С, PIN-код и отпечаток, снимки чеков (готово); облако (Яндекс Диск, Google Drive) — позже.
3. **Этап 2** — финансы: переводы, курсы ЦБ, метка «Семья», долги и регулярные платежи, бюджет, цели и вклады, статистика и выгрузка в Excel (готово).
4. **Резервные копии** (готово).
5. **Проверка безопасности**, первый проход (готово, [docs/security-1.md](docs/security-1.md)).
6. **ИИ и отчёт по переработкам** — фото нарядов и таблица переработок по дням и часам: заполняется вручную или с помощью ИИ по фото. Отчёт — таблица Excel и папка с нарядами, у каждого наряда имя «Наряд … с … по …».
7. **Облако** — Яндекс Диск и Google Drive (отложено).
8. **Этап 3** — свой сервер (VPS или NAS) и общий доступ для семьи и коллег; второй проход проверки безопасности.
