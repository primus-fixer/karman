# Карман

Приложение для компьютера (Windows) и телефона (Android): личные деньги и командировки в одном месте.
Суточные, авансовые отчёты для 1С, долги и синхронизация между устройствами без чужих серверов.

Макет интерфейса — в артефакте «Карман» в Claude. Правила расчёта командировок — в [docs/rules.md](docs/rules.md).

## Что сейчас готово

**Этап 1, шаг 1** — приложение на настоящих данных:

- обзор: «Мои деньги», подотчётные, что вернуть компании и что она должна;
- лента операций по дням — всё, личное, поездки;
- поездки по заявке из 1С: аванс, суточные, расходы с документами и без, расчёт с компанией;
- отчёт для 1С — заявка и авансовый отчёт с копированием полей, сверх бюджета с обоснованием;
- быстрый ввод с метками «поездка», «личное», «личное, метка поездки» и отметкой чека, QR-код кассового чека;
- счета и остатки, валюты, ставка суточных, темы оформления;
- зашифрованная база и связь устройств по Wi-Fi из этапа 0.

Как установить и что проверить — [docs/stage-1.md](docs/stage-1.md). Проверки этапа 0 — [docs/stage-0.md](docs/stage-0.md).

## Как устроено

```
crates/karman-core/   ядро на Rust: деньги, даты, расчёт поездок, база, синхронизация, QR
app/                  приложение Tauri 2: интерфейс (React) и мост к ядру (src-tauri)
scripts/              донастройка Android-проекта при сборке
.github/workflows/    проверки и сборки
docs/                 правила расчёта и план проверки
```

Одно ядро на Rust работает и на Windows, и на Android. Интерфейс — веб-страница внутри приложения,
поэтому экраны одинаковые на обоих устройствах.

Синхронизация: каждое изменение — событие в журнале с номером от устройства. Устройства обмениваются
недостающими событиями, при споре побеждает более позднее изменение. Wi-Fi, облако и свой сервер
передают одни и те же зашифрованные пакеты.

## Сборки

Каждый пуш запускает «Сборки» в Actions. Готовые файлы — в разделе Artifacts у запуска:

- `karman-windows` — установщик `.exe` и `.msi`;
- `karman-android` — `.apk` для телефона. С секретами `ANDROID_KEYSTORE` и `ANDROID_KEYSTORE_PASSWORD`
  он подписан постоянным ключом и обновляется поверх, без них — отладочная сборка.

## Разработка

Нужны Rust, Node.js 22, для Android — Android Studio с NDK.

```bash
cargo test -p karman-core        # тесты ядра
cargo run -p karman-core --example demo_snapshot > demo.json   # сводка на демо-данных макета
cd app && npm ci
npm run tauri dev                # приложение на компьютере
npm run tauri android dev        # на телефоне по USB
```

## План

1. **Этап 0** — проверки на устройствах (готово).
2. **Этап 1** — первая версия: быстрый ввод, лента, поездки и отчёт для 1С (готово); дальше — ключ базы в хранилище системы и PIN, снимки чеков, облако (Яндекс Диск, Google Drive).
3. **Этап 2** — финансы: бюджет, цели, вклады, долги, статистика.
4. **Этап 3** — свой сервер (VPS или NAS) и общий доступ для семьи и коллег.
