# Карман

Приложение для компьютера (Windows) и телефона (Android): личные деньги и командировки в одном месте.
Суточные, авансовые отчёты для 1С, долги и синхронизация между устройствами без чужих серверов.

Макет интерфейса — в артефакте «Карман» в Claude. Правила расчёта командировок — в [docs/rules.md](docs/rules.md).

## Что сейчас готово

**Этап 1** — приложение на настоящих данных:

- обзор: «Мои деньги», подотчётные, что вернуть компании и что она должна;
- лента операций по дням — всё, личное, поездки;
- поездки по заявке из 1С: аванс, суточные, расходы с документами и без, расчёт с компанией;
- отчёт для 1С — заявка и авансовый отчёт с копированием полей, сверх бюджета с обоснованием;
- быстрый ввод с метками «поездка», «личное», «личное, метка поездки», QR-код кассового чека;
- снимки и файлы чеков в зашифрованной базе, обмен ими по Wi-Fi, архив чеков поездки для офиса;
- счета и остатки, валюты, ставка суточных, темы оформления;
- вход по PIN-коду, отпечатку пальца (Android) или Windows Hello; ключ базы — в хранилище системы;
- зашифрованная база и связь устройств по Wi-Fi из этапа 0.

Как установить и что проверить — [docs/stage-1.md](docs/stage-1.md). Проверки этапа 0 — [docs/stage-0.md](docs/stage-0.md).

**Этап 2** — личные финансы, идёт частями ([docs/stage-2.md](docs/stage-2.md)):

- переводы между своими счетами: снятие наличных, обмен валюты — «Мои деньги» не меняются;
- курсы ЦБ на дату операции (с сайта ЦБ запрашивается только дата), запасные курсы в настройках;
- метка «Семья» для общих расходов;
- синхронизация разных версий: устройства знают версии друг друга и подсказывают, какое обновить;
- долги «я должен» и «мне должны», кредиты с графиком платежей;
- регулярные платежи: «Оплачено» и «Пропустить», автоплатежи записываются сами;
- напоминания: уведомления Android и Windows (без сумм), за сколько дней — в настройках;
- «Отложено»: накопительные счета и вклады отдельно от «Моих денег», прогноз процентов по вкладам;
- цели с переводами на копилку и суммой «сколько откладывать в месяц»;
- бюджет на месяц: личный и семейный, общий лимит и по категориям, подсказка при вводе;
- статистика за месяц, квартал и год: расходы по категориям, доходы и расходы по месяцам, командировки за год;
  выгрузка в Excel на компьютере.

**Резервные копии** (0.9.0, [docs/backup.md](docs/backup.md)): все записи и снимки чеков в одном файле,
зашифрованном паролем копии; автокопии на компьютере в выбранную папку (например, Яндекс Диска),
восстановление на компьютере и на телефоне — записи добавляются к нынешним.

**Переработки** (0.10.0, [docs/overtime.md](docs/overtime.md)): в карточке поездки — раздел «Наряды»: снимки
нарядов и таблица по дням; часы с коэффициентами 1,5 и 2 считаются сами по производственному календарю;
общая таблица за месяц из всех поездок; отчёт — таблица Excel как в образце и папка с PDF нарядов;
сумма к оплате — только на экране.

**Коннектор для Claude** (0.11.0, [docs/claude.md](docs/claude.md)): «Карман» на компьютере подключается
к приложению Claude как расширение — Claude отвечает на вопросы о деньгах и поездках, а если разрешить запись —
записывает операции, рабочие дни и наряды, создаёт поездки и собирает отчёт по переработкам; каждое действие
видно в «Кармане» и отменяется кнопкой «Вернуть».

**ИИ: распознавание нарядов** (0.12.0, [docs/ai.md](docs/ai.md)): Claude читает снимки или PDF наряда-допуска
и заполняет наряд и время работы по дням — по правилу таблицы переработок, без дней до ввода в бригаду;
перед записью — экран проверки, после — «Вернуть». Ключ API Claude — свой на каждом устройстве, хранится
зашифрованным и никуда не копируется. Тот же наряд можно разобрать и в приложении Claude через коннектор —
по подписке, без ключа, с теми же правилами времени.

**ИИ по документам и данным** (0.13.0, [docs/ai.md](docs/ai.md)): ввод фразой («такси 640 до объекта, чек есть»
заполняет форму), билеты, счета гостиниц и чеки по снимку, новая поездка из приказа или заявки, подсказка
категории по истории (без ИИ); «Спросить Claude» в самом «Кармане» — на тех же инструментах, что коннектор,
запись только по разрешению и с «Вернуть»; проверка авансового отчёта перед сдачей; сводка месяца —
траты против обычного, крупные покупки, подписки и прогноз на конец месяца.

**Личное облако** (0.13.0, [docs/cloud.md](docs/cloud.md)): обмен записями и снимками чеков через Яндекс Диск —
вход по логину и паролю приложения (WebDAV) — или свой сервер WebDAV. В папке «Карман» на Диске только
зашифрованные файлы; ключ облака открывается паролем копий, пароль приложения хранится только на устройстве.

**Категории трат и настройки** (0.14.0, [docs/categories.md](docs/categories.md)): двенадцать новых категорий
трат (здоровье, одежда, дети, подписки, автомобиль и другие) и свои категории с иконкой из набора — на всех
устройствах, в бюджете, статистике, выгрузке и у Claude; любую категорию, кроме «Другое», можно скрыть. Разделы
настроек под катом, кнопка «Обновить курс ЦБ», при выключенных автокопиях «Обзор» не напоминает о копиях;
расцветка «Щит» теперь «Север», новая иконка «Ленты», этапы поездки по центру.

**Обмен по Wi-Fi: поиск и связь по коду** (0.15.0, [docs/wifi.md](docs/wifi.md)): устройства в одной сети
находят друг друга сами, связываются один раз по коду из восьми знаков (на телефоне — по QR-коду) и дальше
обмениваются сами, пока «Карман» открыт; связанные устройства — со списком, «Обменяться» и «Отвязать».
Код по сети не передаётся (SPAKE2), у каждой пары свой ключ; чужим в сети «Карман» не отвечает.

## Как устроено

```
crates/karman-core/   ядро на Rust: деньги, даты, поездки, долги и платежи, бюджет, накопления, статистика и сводка месяца, выгрузка в Excel, переработки и производственный календарь, запросы к Claude (наряды, фраза, документы, чат, проверка отчёта), инструменты и протокол MCP для Claude, резервные копии, обмен через облако (шифрование файлов), база, синхронизация, связь по Wi-Fi (поиск в сети, код и SPAKE2, ключи пары), PIN-код, курсы ЦБ
crates/karman-cloud/  облако: Яндекс Диск и свой сервер по WebDAV; вход по коду (Яндекс, Google) — для сборок с регистрацией приложения
crates/karman-secure/ ключ базы в хранилище системы (DPAPI, Android Keystore) и Windows Hello
app/                  приложение Tauri 2: интерфейс (React) и мост к ядру (src-tauri)
scripts/              донастройка Android-проекта при сборке
.github/workflows/    проверки и сборки
docs/                 правила расчёта и план проверки
```

Одно ядро на Rust работает и на Windows, и на Android. Интерфейс — веб-страница внутри приложения,
поэтому экраны одинаковые на обоих устройствах.

Синхронизация: каждое изменение — событие в журнале с номером от устройства. Устройства обмениваются
недостающими событиями, при споре побеждает более позднее изменение. Wi-Fi, облако и свой сервер
передают одни и те же зашифрованные пакеты.

## Сборки

Каждый пуш запускает «Сборки» в Actions. Готовые файлы — в разделе Artifacts у запуска:

- `karman-windows` — установщик `.exe` и `.msi`;
- `karman-android` — `.apk` для телефона. С секретами `ANDROID_KEYSTORE` и `ANDROID_KEYSTORE_PASSWORD`
  он подписан постоянным ключом и обновляется поверх, без них — отладочная сборка.

## Разработка

Нужны Rust, Node.js 22, для Android — Android Studio с NDK.

```bash
cargo test -p karman-core        # тесты ядра
cargo run -p karman-core --example demo_snapshot > demo.json   # сводка на демо-данных макета
cd app && npm ci
npm run tauri dev                # приложение на компьютере
npm run tauri android dev        # на телефоне по USB
```

## План

1. **Этап 0** — проверки на устройствах (готово).
2. **Этап 1** — первая версия: быстрый ввод, лента, поездки и отчёт для 1С, PIN-код и отпечаток, снимки чеков (готово); облако — в 0.13.0.
3. **Этап 2** — финансы: переводы, курсы ЦБ, метка «Семья», долги и регулярные платежи, бюджет, цели и вклады, статистика и выгрузка в Excel (готово).
4. **Резервные копии** (готово).
5. **Проверка безопасности**: первый проход (готово, [docs/security-1.md](docs/security-1.md)), второй — облако, ИИ и коннектор (готово, 0.13.1, [docs/security-2.md](docs/security-2.md)): взаимная проверка посредника коннектора, удаление в облаке только своих файлов, запрет самых простых паролей копий, удаление записей в «Спросить Claude» — по кнопке; третий — связь по Wi-Fi (готово, 0.15.0, [docs/security-3.md](docs/security-3.md)); обновление базы (0.15.1): SQLCipher 4.20 с SQLite 3.54.1 закрывает уязвимость SQLite RUSTSEC-2026-0502, найденную проверкой библиотек.
6. **Переработки, коннектор и ИИ**, по шагам:
   - **отчёт по переработкам** (готово, 0.10.0, [docs/overtime.md](docs/overtime.md)) — наряды и таблица по дням в карточке поездки, общая таблица за месяц; отчёт — таблица Excel и папка с нарядами «Наряд 4-30 с 06.10.2026 по 12.10.2026.pdf»; сумма к оплате — только на экране;
   - **коннектор для Claude** (готово, 0.11.0, [docs/claude.md](docs/claude.md)) — «Карман» на компьютере подключается к приложению Claude как расширение: Claude читает сводку, операции, поездки, переработки, бюджеты и долги, а если в настройках разрешена запись — записывает операции, дни и наряды, создаёт поездки и собирает отчёт по переработкам; каждое действие Claude видно в «Кармане» и отменяется кнопкой «Вернуть»; работает, пока «Карман» запущен и разблокирован;
   - **ИИ (Claude) в «Кармане»: подключение и распознавание нарядов** (готово, 0.12.0, [docs/ai.md](docs/ai.md)) — ключ API на каждом устройстве свой, зашифрованный; наряд читает Claude Opus 5.5, проверку ключа делает Haiku 5.5; время дней — по правилу таблицы (будни с 8:00 и до конца допуска, но не раньше 17:00, выходные и вечерний допуск — по наряду, дни до ввода в бригаду не берутся); перед записью — экран проверки, свои дни без спроса не заменяются; счётчик запросов с оценкой стоимости; в коннекторе — «Дни по наряду» и «Записать наряд с днями»: наряд, прочитанный Claude в приложении, считается по тем же правилам и записывается одним действием после согласия;
   - **ИИ в «Кармане»: остальные документы** (готово, 0.13.0) — ввод фразой (Haiku 5.5), билеты, счета гостиниц и чеки, поездка из приказа или заявки (Opus 5.5), подсказка категории по истории без ИИ;
   - **ИИ по данным** (готово, 0.13.0) — «Спросить Claude» в самом «Кармане» (Sonnet 5.5) на тех же инструментах, что коннектор: Claude сам запрашивает нужные данные, запись — отдельным переключателем, каждое действие с «Вернуть»; проверка отчёта перед сдачей; сводка месяца — необычные траты, крупные покупки, подписки и прогноз — считается «Карманом», Claude её пересказывает.
7. **Облако** (готово, 0.13.0, [docs/cloud.md](docs/cloud.md)) — Яндекс Диск по логину и паролю приложения (WebDAV) или свой сервер WebDAV; в облаке только зашифрованные файлы. Google Drive — позже: ему нужна регистрация приложения.
8. **Категории и настройки** (готово, 0.14.0, [docs/categories.md](docs/categories.md)) — новые и свои категории трат, разделы под катом, «Обновить курс ЦБ».
9. **Обмен по Wi-Fi: поиск и связь по коду** (готово, 0.15.0, [docs/wifi.md](docs/wifi.md)) — устройства в сети находят друг друга, связь по коду из восьми знаков (SPAKE2) или QR-коду, связанные устройства обмениваются сами.
10. **Этап 3** — свой сервер (VPS или NAS) и общий доступ для семьи и коллег; коннектор для claude.ai и телефона (удалённый, со входом); третий проход проверки безопасности.
